## 0.2.0

- Add the "Other calls: Shown / Hidden" toggle. Hidden shows only `track` events, numbered in sequence.
- The display modes now persist across app runs (`localStorage`).
- Require `devtools_app_shared` and `devtools_extensions` 0.5.1 or newer. Older versions do not compile with the tab.

## 0.1.0

- First version: Mixpanel tab with a live list, property table, Mixpanel-props toggle, search,
  flush, JSON / CSV / Markdown export, and history across hot restarts.
- Reference recorder and demo app in `example/`.
